# 4by4 Connect

A clean two-player Connect Four game built with vanilla HTML, CSS, and JavaScript.

## Features

- 6×6 game board
- Two-player gameplay
- Horizontal and vertical win detection
- Winning pieces highlighted
- Draw detection
- Score tracking
- Responsive design
- Restart/new game functionality

## Built With

- HTML
- CSS
- JavaScript

## How to Run

Open `index.html` in a browser.
